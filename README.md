# おゆずりぼん

専修大学の学生を対象とした、教科書リユース・譲渡Webサービスです。

## 公開サイト

https://oyuzurebbon.net/

> 本サービスは、専修大学から配布された指定ドメインのGoogleアカウントのみログインできます。
> ログイン後の主要画面については、下記のスクリーンショットをご覧ください。

## サービス概要

不要になった教科書を、必要とする学生へ無償で譲渡するためのWebサービスです。

譲り手が教材の写真や授業情報を登録し、貰い手が受け取りを申し込むことで取引が始まります。受け渡しには大学構内の指定ロッカーを使用するため、利用者同士が直接顔を合わせたり、受け渡し日時を相談したりする必要がありません。

## 主な機能

- 専修大学のGoogleアカウントに限定したログイン認証
- 教材名・授業名・教授名による検索と絞り込み
- 教材写真の撮影・アップロード
- 教材の譲渡登録
- 受け取り申し込み
- ロッカーを利用した非対面の受け渡し
- 出品・取引状況・期限を確認できるマイページ
- 受け取り情報の画像保存
- お問い合わせフォーム

## 開発体制

プロジェクト全体は教員を含む10名で、そのうちWebサイトの開発は私を含む5名で行いました。

私は主に開発の進行を担い、以下の機能を担当しました。

- Google OAuth 2.0を利用した指定ドメイン限定のログイン認証
- 譲渡登録画面のカメラ機能
- 受け取り申し込み完了画面の画像保存機能
- マイページの追加
- お問い合わせページの追加
- Google Apps Scriptの修正
- レスポンシブ対応と既存機能の改善
- GitHubとさくらVPSを利用した公開・運用

## 開発背景

大学の講義は長くても3か月程度で終了するため、購入した教科書が十分に使用されないまま不要になることがあります。

そこで、不要になった教科書を必要とする学生へ譲ることで、教材の「もったいない」を減らすことを目的として開発しました。

当初は教科書以外の物品や一般利用も検討しましたが、大学構内のロッカーを利用することや、検索・絞り込みの分かりやすさを考慮し、「教科書のみ」「専修大学生のみ」に対象を絞りました。

## 工夫した点

### 金銭・対面・日程調整を不要にしたこと

既存のフリマサービスとの差別化として、金銭のやり取りを発生させず、大学構内の指定ロッカーを利用する仕組みにしました。

### 大学関係者に利用者を限定したこと

Google OAuth 2.0を利用し、専修大学から配布された指定ドメインのアカウントだけがログインできるようにしました。

### スマートフォンの操作性を改善したこと

検索バー、絞り込みメニュー、ヘッダー、カメラ、画像選択などを、スマートフォンで実際に確認しながら改善しました。

### 公開後の運用まで行ったこと

さくらVPS、Nginx、Dockerを利用して公開環境を構築し、API、画像保存、サーバーログなどを確認しながら不具合を調査しました。
